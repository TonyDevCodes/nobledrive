# NOBLEDRIVE - VIP Electric Chauffeur Booking Platform

A boutique VIP electric chauffeur service based in Rotterdam, offering premium hotel-to-airport transfers (AMS, RTM, EIN) through a hotel-referral partnership model.

**Live site:** [nobledrive.nl](https://nobledrive.nl)

> ⚠️ This repository is a **showcase only**. Proprietary business logic and source code are private and not published here.

## What I Built

Designed and developed the complete booking platform from scratch, including custom booking logic, payment automation, driver management system, and a Progressive Web App for drivers.

## Key Features

- **Custom Booking Engine** Real-time calendar with exact-time collision detection, supporting one-way and round-trip bookings
- **EV Range Algorithm** Custom logic to plan multi-leg routes within electric vehicle range limits
- **Driver Rotation System** Automated 6-week fair rotation across the driver fleet
- **Payment & Refund Automation** Full Mollie integration with tiered cancellation policy handling
- **Driver PWA** Installable mobile app with secure PIN authentication and live booking management
- **Multilingual** Fully localized in English, German, French, and Dutch
- **Admin System** Booking management, payment monitoring, loyalty tracking, and driver scheduling
